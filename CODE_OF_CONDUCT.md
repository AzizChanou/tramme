# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). By taking part (issues, pull requests, discussions, reviews), you agree to it.

## In short

- Be respectful and welcoming, whatever someone's background, experience or identity.
- Give and accept feedback on the work, never on the person.
- No harassment, insults, sexualized language or imagery, or publishing others' private information.
- Assume good faith, and help newcomers find their way.

## Scope

It applies in every project space (the repository, its issues and discussions) and when you represent the project elsewhere.

## Reporting

If you see or experience unacceptable behavior, contact the maintainer privately through GitHub (the maintainer's profile, or a private security report if nothing else fits; see [SECURITY.md](SECURITY.md)). Reports are handled confidentially.

## Enforcement

The maintainer may remove, edit or reject comments, commits, code and issues that do not follow this code. Depending on the case: a private warning, a temporary ban, or a permanent ban, following the [Contributor Covenant enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
